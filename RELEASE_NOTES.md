## Medal Detector 2.0.0

The first public release. Medal Detector tracks every Torn honour and medal, shows your next award for each stat, and lets you set daily goals to get there. It uses only the official Torn API.

**[Install medal-detector.user.js](https://raw.githubusercontent.com/Eaglewing91/Medal-Detector/main/medal-detector.user.js)** (needs Tampermonkey)

### Highlights
- **Honours and Medals pages** with search, filters and expandable award paths
- **Goals for anything:** every honour, medal and stat in one picker, including in-game-only awards that tick off when Torn gives them to you
- **Overview** with today's goals and your closest awards sorted by estimated time
- **Sidebar list** of your goals under Merits, with finished ones hidden
- **Drug cooldowns** built into the estimates
- **All 392 honours** checked by hand: 184 tracked live, 208 listed as in-game only

### Setup
1. Install the script.
2. Open it from **Medal Detector [open]** under Merits in Torn's sidebar.
3. In **Settings**, create a **Limited** API key with the link provided and paste it in.
